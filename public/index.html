What is inside

Request parser

Request line, headers and Content-Length bodies, with size limits and 400/413 on bad input.

Router

Exact and parameterised paths like /users/:id, query strings, automatic HEAD and 405 with Allow.

Static files

MIME types from file extensions, directory index pages and protection against ../ path traversal.

Thread pool

Connections run on a fixed pool of workers, so one slow client never blocks the others.

Keep-alive

This page and its assets share one TCP connection; pipelined requests are answered in order.

Graceful shutdown

Ctrl+C stops accepting new clients and lets in-flight requests finish before exiting.

JSON API

Fetched from GET /api when this page loaded.
